Подобие параметра self из Python это this

Python
class Some:
    def __init__(self, some_variable):
        self.__some_variable = some_variable

    @staticmethod
    def some_function(some_parameter):
        self.__some_variable = some_parameter

Java
class Some{
    private String some_variable;
    public void some_function(some_parameter){
        this.some_variable = some_parameter
    }
}

Можно создать функцию с несколькими аргументами
public int summ(int a, int b){return a + b;}

переопределение существуюищих функций с одинаковыми типами аргументов запрещено
переопределить функцию нельзя

Но можно расширить функцию для принятия различными типами данных
public int summ(int a, int b){return a + b;}
public double summ(double a, double b){return a + b;}
Одинаковое название, но технически разные функции

Основа или абстрактный класс (Две схожии реализации)
public interface Animal{}
public abstract class Animal{}

Абстрактный метод создан для переопределения в классах наследниках
public abstract class Animal{
public abstract void eat();
public int age;
}
public interface Animal{
void eat();
int age;
}

Базовое наследование
public class Cat extends Animal{}

Полное наследование с переопределением методов родительского класса
Где @Override = переопределение
// public class Cat implements Animal{ при interface
public class Cat extends Animal{
@Override public void eat(){System.out.println("Cat is eating");}
public void meow(){System.out.println("Meow!");}
public String favorite_food;
}

Создание объекта дочернего класса с помощью наследования без нового метода meow
Animal cat_Tom = Cat();
Создание объекта дочернего класса с помощью полиморфизма с новым методом meow
Cat cat_Tom = Cat();

Пример
Cat cat_Tom = Cat();
cat_Tom.age = 4;
cat_Tom.favorite_food = "fish";
cat_Tom.eat();
cat_Tom.meow();

Для каждого класса public должен быть отдельный файл .java
